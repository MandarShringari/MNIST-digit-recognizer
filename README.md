# MNIST Digit Recogniser

A neural network built from scratch using only NumPy and Pandas, trained to
classify handwritten digits (0–9) from the MNIST dataset.

## Goals

- Implement forward propagation, backpropagation and gradient descent by hand,
  without deep learning frameworks
- Classify 28×28 greyscale images of handwritten digits
- Experiment with techniques to improve accuracy and training efficiency,
  such as better weight initialisation, mini-batch training, the Adam optimiser
  and regularisation
- Compare results against a framework-based model (e.g. PyTorch)
